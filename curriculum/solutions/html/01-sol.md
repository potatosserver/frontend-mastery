# 解答：01. 骨架與編碼

### 實作目標
建立一個正確的 HTML5 基礎結構，包含 UTF-8 編碼與語言設定。

### 專業代碼實現
```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>專業作品集 | 你的名字</title>
</head>
<body>
    <!-- 內容將在後續章節填充 -->
</body>
</html>
```

### 設計意圖
- `<!DOCTYPE html>`：確保瀏覽器不進入怪異模式。
- `lang="zh-Hant"`：提升 SEO 與無障礙支持。
- `UTF-8`：防止中文亂碼。
