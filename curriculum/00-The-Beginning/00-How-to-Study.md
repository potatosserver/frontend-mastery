# 00. 啟動指南：如何掌握本教材 (How to Study)

歡迎來到《前端工程終極精通》學習體系！本教材旨在將你從一名初學者，培養成一名具備 **工業級實作能力** 的專業前端工程師。

這不是一本讓你「閱讀」的書，而是一套讓你 **「實作」** 的訓練系統。

---

## 🎯 核心理念：累進式主專案 (Cumulative Project)

本教材不使用碎片化的練習題。你將從第一章開始，共同打造一個 **《專業個人品牌網站 (Professional Portfolio Site)》**。

### 成長階段圖 (The Roadmap)

你將經歷五個心智模型轉型階段：

| 階段 | 模組 | 核心目標 | 最終成果 |
| :--- | :--- | :--- | :--- |
| **1. 視覺直覺期** | `01-HTML` $\rightarrow$ `02-CSS` $\rightarrow$ `03-M3` | 建立資訊層級 $\rightarrow$ 現代美學 $\rightarrow$ 標準化組件 | 具有工業級視覺的靜態頁面 |
| **2. 邏輯掌控期** | `04-JS Mastery` | 從基礎語法 $\rightarrow$ 異步工程 $\rightarrow$ 引擎原理 | 具有靈魂的互動應用 |
| **3. 環境感知期** | `05-F12` $\rightarrow$ `06-Browser` $\rightarrow$ `07-Net` | 掌握開發工具 $\rightarrow$ 瀏覽器能力 $\rightarrow$ 網路通訊 | 能獨立調試並與伺服器高效對接 |
| **4. 專業升級期** | `08-TypeScript` $\rightarrow$ `09-Framework` | 靜態分析救贖 $\rightarrow$ 聲明式 UI $\rightarrow$ 全局狀態管理 | 構建可維護的大規模工業應用 |
| **5. 工程封頂期** | `10-QA` $\rightarrow$ `11-Performance` | 測試金字塔 $\rightarrow$ CI/CD $\rightarrow$ Core Web Vitals | 達到 100 分性能的卓越產品 |

---

## 🔄 學習迴路 (The Learning Loop)

為了確保你真正掌握知識，請嚴格遵循以下 **「學習迴路」**：

1. **閱讀理論** $\rightarrow$ 理解「為什麼要這樣做」，而非死記語法。
2. **主專案實作** $\rightarrow$ 按照章節中的「實作挑戰」將功能疊加到你的專案中。
3. **對比快照 (Snapshot)** $\rightarrow$ 卡住時，參考 `/curriculum/snap-xxx/` 觀察專業工程師的最終成果。
4. **驗證解答 (Solutions)** $\rightarrow$ 檢查邏輯是否正確 $\rightarrow$ 參考 `/curriculum/solutions/xxx/`。
5. **反思與優化** $\rightarrow$ 嘗試修改參數 $\rightarrow$ 觀察變化 $\rightarrow$ 直到完全理解。

---

## 🛠️ 工具鏈設定 (Tooling)

建議安裝以下工業標準工具：
- **編輯器**：[Visual Studio Code](https://code.visualstudio.com/) (必裝)。
- **擴充功能**：安裝 **Live Server** $\rightarrow$ 實現即時預覽。
- **瀏覽器**：[Google Chrome](https://www.google.com/chrome/) $\rightarrow$ 熟練使用 **F12 開發者工具 (DevTools)**。
