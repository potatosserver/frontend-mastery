# 00. 如何學習這套教材 (How to Study)

歡迎來到《前端極致基礎強化》學習路徑！本教材旨在將你從一個完全不懂程式碼的初學者，培養成一名具備工業級實作能力的專業前端工程師。

這不是一本讓你「閱讀」的書，而是一套讓你「實作」的訓練系統。

---

## 1. 核心學習理念：累進式主專案 (Cumulative Project)

本教材的核心是 **「實作導向」**。你不需要在每個章節寫碎片化的練習題，而是會從第一章開始，共同打造一個 **《專業個人品牌網站 (Professional Portfolio Site)》**。

### 什麼是累進式主專案？
- **HTML 階段** $\rightarrow$ 在 `01-HTML-Mastery/` 學習 $\rightarrow$ 最終成果在 `snap-html/`。
- **CSS 階段** $\rightarrow$ 在 `02-CSS-Mastery/` 學習 $\rightarrow$ 最終成果在 `snap-css/`。
- **JS 階段** $\rightarrow$ 在 `03-JS-Mastery/` 學習 $\rightarrow$ 最終成果在 `snap-js/`。

**最終目標**：當你完成前三個模組後，你將擁有一份可以在 GitHub Pages 上線、足以向雇主展示的專業作品集。

---

## 2. 學習迴路 (The Learning Loop)

為了確保你真正掌握知識，請遵循以下 **「學習迴路」**：

1. **閱讀理論** $\rightarrow$ 理解為什麼要這樣做，而不是只記住語法。
2. **主專案實作** $\rightarrow$ 按照章節中的「實作挑戰」將功能疊加到你的 `index.html` 中。
3. **對比快照 (Snapshot)** $\rightarrow$ 如果你卡住了，或者想想專業工程師會怎麼寫，請參考 `snap-html/`, `snap-css/` 或 `snap-js/` 資料夾。
4. **驗證解答 (Solutions)** $\rightarrow$ 檢查你的代碼邏輯是否正確 $\rightarrow$ 參考 `sol-html/`, `sol-css/` 或 `sol-js/` 資料夾。
5. **反思與優化** $\rightarrow$ 嘗試修改參數，看看會發生什麼，直到你完全理解。

---

## 3. 工具鏈設定 (Tooling)

為了獲得最佳體驗，建議安裝以下工具：

- **編輯器**：[Visual Studio Code](https://code.visualstudio.com/) (必裝)。
- **擴充功能**：安裝 **Live Server** 擴充插件 $\rightarrow$ 讓你可以即時看到修改後的網頁效果。
- **瀏覽器**：[Google Chrome](https://www.google.com/chrome/) $\rightarrow$ 熟練使用 **F12 開發者工具 (DevTools)**。

---

## 4. 導航系統 (Navigation)

本教材的所有檔案底部都設有導航連結。你可以像翻書一樣，在「上一章 $\rightarrow$ 解答 $\rightarrow$ 下一章」之間快速切換。

**現在，請準備好好你的編輯器，讓我們從 `01-HTML-Mastery/01-skeleton-and-encoding.md` 開始，搭建你的第一個專業網站！**
