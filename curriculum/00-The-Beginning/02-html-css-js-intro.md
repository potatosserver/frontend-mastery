# 02. HTML/CSS/JS 的角色分工 (The Holy Trinity of Web)

如果你把一個網頁比作一棟建築物，那麼 HTML、CSS 和 JavaScript 分別扮演著最不可或缺的三個角色。

## 1. HTML (HyperText Markup Language)：骨架與結構

HTML 不是程式語言，而是一種 **「標記語言」**。它的作用是定義網頁的**內容**與**結構**。

- **角色**：骨架 (Skeleton) / 牆壁。
- **負責的事**：
  - 這裡應該是一個標題 (`<h1>`)。
  - 這裡應該是一個段落 (`<p>`)。
  - 這裡應該是一個按鈕 (`<button>`)。
  - 這裡應該放一張圖片 (`<img>`)。
- **專業視角**：HTML 決定了網頁的**資訊層級**。一個好的 HTML 結構不僅能讓開發者好維護，更能讓 Google 的爬蟲 (Crawler) 快速理解你的網站在講什麼 (這就是 SEO 的基礎)。

---

## 2. CSS (Cascading Style Sheets)：皮膚與視覺

CSS 是一種 **「樣式表語言」**。它的作用是定義網頁的**外觀**。

- **角色**：皮膚 (Skin) / 裝潢。
- **負責的事**：
  - 這個標題要用 24px 的字體，顏色要是深藍色。
  - 這個按鈕要圓角，背景要是漸層色。
  - 網頁在手機上要顯示一列，在電腦上要顯示三列 (響應式佈局)。
  - 元素從左到右滑入的動畫效果。
- **專業視角**：CSS 決定了**使用者體驗 (UX)** 的第一印象。專業的 CSS 寫法會注重「可維護性」 (例如使用 CSS 變數) 與「性能」 (減少重繪 Reflow)。

---

## 3. JavaScript (JS)：肌肉與邏輯

JavaScript 是一門真正的 **「程式語言」**。它的作用是定義網頁的**行為**與**互動**。

- **角色**：肌肉 (Muscle) / 電路與自動化。
- **負責的事**：
  - 當使用者點擊按鈕時，彈出一個視窗。
  - 從伺服器獲取即時數據 (例如：車輛剩餘數量) 並動態更新到畫面上。
  - 檢查使用者輸入的 Email 格式是否正確。
  - 實作地圖的縮放與標記點切換。
- **專業視角**：JS 決定了網頁的**功能深度**。從簡單的介面切換，到複雜的單頁應用 (SPA)，全部依賴於 JS 對 DOM (文件物件模型) 的操作。

---

## 💡 綜合實例：一個「登入按鈕」的誕生

讓我們看看這三者是如何協作完成一個簡單功能的：

1. **HTML**：定義一個按鈕 $\rightarrow$ `<button id="login-btn">登入</button>` (告訴瀏覽器：這裡有個按鈕)。
2. **CSS**：定義按鈕樣式 $\rightarrow$ `#login-btn { background: blue; color: white; border-radius: 5px; }` (告訴瀏覽器：按鈕要藍底白字且有圓角)。
3. **JS**：定義按鈕行為 $\rightarrow$ `document.getElementById('login-btn').onclick = () => { alert('登入成功！'); }` (告訴瀏覽器：點擊時要跳出提示)。

---

## 🛠️ 案例分析：一個「即時交通查詢網頁」是如何構成的？

即使你還沒有開始寫代碼，也可以試著分析一個典型的專業網頁（例如：YouBike 或 Google Maps）是如何分工的：

- **HTML 部分 (結構)**：定義了頂部的搜尋框、中間的地圖容器、以及底部顯示站點資訊的卡片清單。
- **CSS 部分 (視覺)**：定義了卡片的圓角陰影、深色模式的背景色、以及在地圖上顯示不同顏色標記的樣式。
- **JS 部分 (邏輯)**：處理使用者的搜尋輸入 $\rightarrow$ 發送 API 請求 $\rightarrow$ 計算使用者與站點的距離 $\rightarrow$ 動態在畫面上增加或移除站點卡片。

**如果你能分辨出一個網頁功能中哪些部分屬於 HTML、CSS 和 JS，你就已經準備好進入真正的開發階段了。**
